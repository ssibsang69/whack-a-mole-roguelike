# 두더지 대작전! (Whack-a-Mole Roguelike)

'두더지 대작전!'은 전통적인 두더지 잡기 아케이드에 로그라이크의 증강(Augment) 빌드 조합과 보스 레이드 기믹을 융합한 완성도 높은 브라우저 게임입니다.

---

## 🎮 게임 실행 방법

외부 서버나 추가 패키지 설치 없이 브라우저에서 바로 플레이할 수 있습니다.

### 방법 1. 로컬 개발 서버 실행 (권장)
```bash
npm start
# 또는
node server.js
```
실행 후 브라우저에서 **`http://localhost:3000`** 접속

### 방법 2. 정적 파일 직접 실행
프로젝트 폴더 내 **`index.html`**을 더블 클릭하여 크롬/엣지/사파리 등의 브라우저에서 바로 실행할 수 있습니다.

---

## 🌟 주요 게임 특징

1. **로그라이크 증강 시스템 (Augments)**
   - 일반 두더지 **15마리 처치 시마다** 게임이 일시정지되며 3개의 무작위 증강 중 하나를 선택합니다.
   - 15종의 기본 증강은 최대 3단계까지 강화할 수 있습니다.
   - 특정 증강 조합 시 **시너지 효과**(황금 만개, 뇌전 폭풍, 무한의 난타, 치명타 마스터)가 자동으로 개방됩니다.

2. **3단계 보스 레이드 & 도주(실패) 시스템**
   - **웨이브 3: 두더지 대왕** (빛나는 황금 왕관 약점, 체력 40% 이하 광폭화)
   - **웨이브 6: 철갑 두더지** (철갑 방패 상태 피해 감소, 열린 바이저 틈새 약점, 도주 시 진흙으로 구멍 1개 일시 봉쇄)
   - **웨이브 9: 마왕 두더지** (분신 소환 환영술 패턴, 가짜 타격 시 시간 패널티, 최종 토벌 시 게임 클리어)
   - 30초 내에 보스를 처치하지 못하면 보스가 비웃으며 도망치지만, **플레이어의 점수와 증강은 보존된 채 다음 웨이브로 계속 진행**됩니다!
   - 보스 처치 성공 시 **전설 보스 전용 증강 3종** 중 하나를 보상으로 획득합니다.

3. **콤보 & 타격 피드백**
   - 연속 타격 시 콤보가 누적되며 점수 배율이 최대 4.0배 이상 상승합니다.
   - 타격 시 포물선으로 튀어오르는 점수 팝업, 화면 진동(Screen Shake), 커스텀 망치 스윙 연출이 구현되어 있습니다.

4. **100% 브라우저 자체 합성 사운드 (Web Audio API)**
   - 외부 mp3 파일 없이 Web Audio API를 활용하여 우드 타격음, 황금 차임, 폭발음, 크리티컬 파열음, 레벨업 팡파레, 16비트 적응형 칩튠 BGM을 실시간 합성합니다.
   - 언제든 상단 버튼으로 효과음/BGM을 켜고 끌 수 있습니다.

5. **조작 방식**
   - **마우스 / 모바일 터치**: 원하는 구멍을 직접 터치/클릭
   - **데스크톱 키보드**: **1~9 숫자키** 또는 **QWE / ASD / ZXC** 키로 각 구멍을 즉시 타격 가능 (설정에서 가이드 토글 가능)
   - **필드 확장**: 기본 3x3 (9홀) 외에 4x4 (16홀) 모드를 설정에서 선택 가능합니다.

6. **데이터 저장 & 업적**
   - 최고 점수, 최대 콤보, 누적 처치 수, 12종의 도전 과제가 `localStorage`에 자동 영구 보관됩니다.
